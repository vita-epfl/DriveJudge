#
# What changed vs. v1
#   * 2000 clips: 1000 real (CarCrash Normal) + 1000 generated
#     (cosmos-drive-dreams 566 + cosmos-predict1 434 — see NOTE below), so
#     "always Generated" scores exactly 50 % and no longer wins by default.
#   * <= 3 clips per `scenario_id` (the weather / model-size re-renderings of
#     one scene), so the cluster bootstrap has 1416 small clusters.
#   * stratified: dd over category x weather, p1 over weather x gen_size.
#   * the message lists are ordered **pilot first** — the first 1000 entries
#     are the 500 real + 283 dd + 217 p1 pilot subset.  None of the eval
#     scripts has a --limit flag, so a `*_pilot*.json` copy of every question
#     file is shipped as well; run those first if GPU time is tight.
#
# NOTE on 566/434: cosmos-predict1 has only 494 benchmark clips in total, and
# only 434 of them survive the <=3-per-scenario cap, so an exact 500/500 split
# is impossible.  The builder keeps the cluster cap and moves the 66-clip
# deficit to cosmos-drive-dreams.  Pass --shortfall relax to trade the cap for
# the source balance instead.
#
# BUILD (run locally, needs results/fft/manifest.parquet — NOT on the pod, the
# manifest is built from the local dataset copy):
#   .venv/bin/python src/real_vs_generated/build_realgen_v2.py \
#       --n-real 1000 --n-gen 1000 --pilot 500 --seed 42 \
#       --max-per-cluster 3 --out src/real_vs_generated/v2/
#
# UPLOAD (once): the 1000 CarCrash clips listed in
#   src/real_vs_generated/v2/realgen_v2_real_clips.txt
# must be copied to the PVC as  <final_dataset>/real/NNNNNN.mp4  (keep the
# CarCrash numbering — 000001..003000 do not collide with any generated
# basename, which matters for the agent's basename lookup).  The generated
# clips are already on the PVC.  See HANDOFF_v2.md.
